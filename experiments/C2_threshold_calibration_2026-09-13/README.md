# V4｜V2 模型的 C2 概率诊断与阈值校准

## 实验目标

本实验不重新训练，直接复用当前最佳 V2 权重，判断 C2 在阈值 0.5 下全空预测的原因：

1. 模型已经学到 C2，但输出概率整体低于 0.5；
2. 模型没有形成有效的 C2 正负样本区分能力。

## 固定项

- 权重：V2 C2 定向增强模型；
- 验证划分：`val_size=0.2`、`seed=42`；
- 模型：U-Net + ResNet34；
- 输入：256×800；
- 不重新训练，不修改模型和数据增强。

## 搜索内容

- 分类别阈值：`0.01～0.50`；
- 模型输出空间最小总面积：`0 / 5 / 10 / 25 / 50 / 100 / 200 / 400`；
- 常规 Dice；
- 仅真实正样本 Dice；
- 图片级检出召回率、精确率与 F1；
- 正样本图片、真实缺陷区域和负样本图片的最大预测概率分布。

常规 Dice 会受到大量空掩码影响，因此不能只根据这一项判断 C2。只有当 C2 正样本 Dice、检出召回率以及正负样本概率分布同时合理时，才考虑生成低阈值提交。

## 状态

- 当前状态：Kaggle 概率诊断、离线推理、Code Submission 和排行榜评分均已完成。
- 输出文件：`threshold_results.json`。

## C2 概率诊断

固定验证集中有 49 张 C2 正样本图片。V2 模型对 C2 的输出如下：

| 概率统计 | 中位数 | 90% 分位数 | 最大值 |
|---|---:|---:|---:|
| C2 正样本图片的全图最大概率 | 4.77e-7 | 6.08e-7 | 5.07e-6 |
| C2 真实缺陷区域最大概率 | 0 | 5.96e-8 | 1.19e-7 |
| C2 负样本图片的全图最大概率 | 4.77e-7 | 6.56e-7 | 7.81e-6 |

即使把阈值降至搜索下限 0.01，C2 的正样本 Dice、检出召回率和检出 F1 仍全部为 0。正样本与负样本的最大概率也没有形成有效区分，而且真实 C2 区域的概率更低。因此 C2 问题不是“0.5 阈值过高”，而是模型的 C2 输出通道已塌缩为背景。

## 验证集最优后处理

阈值与最小面积在 256×800 模型输出空间搜索。C1/C2 在所有有效阈值下仍保持空预测，因此提交时保守地维持 0.5；C3/C4 的最优组合如下：

| 类别 | 阈值 | 模型空间最小面积 | Validation Dice |
|---|---:|---:|---:|
| C1 | 0.5（保持原值） | 0 | 0.928799 |
| C2 | 0.5（保持原值） | 0 | 0.980509 |
| C3 | 0.5 | 400 | 0.798460 |
| C4 | 0.075 | 400 | 0.963684 |

四类独立最优 Validation Dice 均值为 `0.917863`，比 V2 原始 `0.912265` 高 `0.005598`。测试推理恢复到 256×1600，因此将模型空间 400 像素近似换算为原图空间 800 像素。

最终推理参数：

```text
thresholds = 0.5,0.5,0.5,0.075
min_total_pixels = 0,0,800,800
TTA = none
```

测试集非空预测数量为 C1=`0`、C2=`0`、C3=`1,960`、C4=`285`，提交文件共 `22,024` 行。

## 结论

V4 成为当前整体分数最好的版本，证明逐类别阈值与面积过滤能改善 C3/C4 的误报和漏报平衡。但它没有改善 C2，不能写成“通过阈值搜索解决了 C2 类别不平衡”。下一次训练实验应针对通道塌缩改变优化目标，优先比较 `Focal + Dice`，并继续记录 C2 正样本 Dice 与检出召回率。
