# V5a｜C2 标签与缩放审计

## 目标

检查训练时把 mask 从 256×1600 最近邻缩放到 256×800，是否导致稀有 C2 缺陷消失或严重缩水。本实验不训练模型。

## 方法

- 从官方 `train.csv` 解码全部 C2 正样本 mask；
- 使用与当前流水线一致的宽度减半最近邻映射；
- 对比缩放前后像素数、8 邻域连通区域数量；
- 因宽度减半本来就会使像素数约减半，使用 `resized_pixels / (original_pixels × 0.5)` 作为归一化像素保留率。

复现：

```bash
python audit_c2_resolution.py \
  --data-dir /path/to/severstal-steel-defect-detection \
  --output-dir /path/to/audit_output
```

## 结果

| 指标 | 结果 |
|---|---:|
| C2 正样本图片 | 247 |
| 缩放后 mask 完全消失 | 0 |
| 归一化像素保留率最小值 | 0.9367 |
| 归一化像素保留率中位数 | 1.0000 |
| 归一化像素保留率 90% 分位数 | 1.0025 |
| 缩放前连通区域总数 | 321 |
| 缩放后连通区域总数 | 323 |
| 出现连通区域减少的图片 | 3 |

原始 C2 mask 像素数中位数为 2,944，缩放后为 1,458；这是宽度减半时预期的约 50% 面积变化。最小 C2 mask 从 316 像素变为 148 像素，仍未消失。

## 结论

当前 256×800 最近邻缩放没有造成 C2 mask 消失或普遍严重缩水，因此不足以解释 V2/V3 中 C2 输出概率接近 0 的通道塌缩。提高分辨率仍可能改善边界细节，但不再是下一步最高优先级。

下一实验应保持 V2 的模型、数据、split、输入尺寸和 C2 定向增强不变，只将 `BCE+Dice` 改为 `Focal+Dice`，直接检验背景像素主导 Loss 是否为 C2 无法学习的重要原因。
