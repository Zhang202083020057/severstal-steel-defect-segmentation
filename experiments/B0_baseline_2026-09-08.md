## 结果解释

平均验证 Dice 为 `0.9063347`。Class 1 和 Class 2 的分数在各 epoch 几乎不变，且分别接近验证集中对应的空掩码比例：

```text
Class 1: (2514 - 179) / 2514 = 0.9288
Class 2: (2514 - 49) / 2514 = 0.9805
```

这说明当前阈值 0.5 下模型很可能没有预测出这两个少数类。总体分数较高，部分原因是竞赛指标规定预测和真实掩码都为空时 Dice=1；因此不能只看平均 Dice，还要关注每一类召回和正样本上的分割质量。详见[Kaggle官方评价说明](https://www.kaggle.com/c/severstal-steel-defect-detection)。
