## 正式基线 B0

```bash
python train.py \
  --data-dir /root/autodl-tmp/kaggle/severstal-steel-defect-detection \
  --output-dir /root/autodl-tmp/kaggle/outputs/B0_unet_resnet34 \
  --architecture unet \
  --encoder resnet34 \
  --encoder-weights imagenet \
  --loss bce_dice \
  --augmentation basic \
  --height 256 \
  --width 800 \
  --epochs 15 \
  --batch-size 4 \
  --learning-rate 0.0003 \
  --num-workers 4
```

## U-Net 在做什么？

- ResNet34 编码器逐步压缩空间尺寸并提取纹理、边缘和缺陷语义；
- U-Net 解码器逐步恢复空间分辨率；
- 跳跃连接将编码器的浅层边界信息传给解码器；
- 最后一层输出四通道 logits。

## ImageNet 预训练是什么意思？

ResNet34 在大型 ImageNet 数据上预先学习过通用边缘和纹理特征。虽然钢板和自然图片不同，这些底层特征通常仍有帮助。预训练不是使用测试集标签，也不等于模型已经学会钢板缺陷。

## BCE-Dice Loss

```text
BCE：逐像素判断对错，优化稳定
Dice Loss：关注预测区域与真实区域的重叠
总 Loss = BCE + Dice Loss
```

训练目标是 Loss 下降；项目评价指标是 Dice 上升，两者不能混为一谈。

## 看训练日志

每个 epoch 会输出：

- `train_loss`：训练损失；
- `val_loss`：验证损失；
- `val_dice`：四类平均验证 Dice；
- `val_dice_class_1..4`：各类别 Dice；
- `learning_rate`：当前学习率。

如果训练 Dice 上升、验证 Dice 长期下降，可能出现过拟合。如果所有类别 Dice 都接近 0，先检查 Mask、阈值、学习率和训练是否真的更新，而不是盲目增加 epoch。

## 显存不足

依次尝试：

1. `--batch-size 2`；
2. `--width 512`；
3. 换显存更大的 GPU。

改变输入尺寸后必须在实验记录中写明，不能与不同尺寸结果直接当作只比较模型架构。
