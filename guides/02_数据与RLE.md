# 02｜数据、Mask 与 RLE

## 一张训练样本是什么？

训练样本不是只有图片，而是：

```text
一张 256×1600 RGB 图片
+
四张 256×1600 二值 Mask
```

四个 Mask 对应 Class 1～4。某一类别不存在时，对应 Mask 全为 0。

## 为什么是多标签分割？

一张图可能同时包含多种缺陷，因此四个类别不能用 Softmax 强制互斥。模型输出四个独立 logits，分别经过 Sigmoid 得到四张概率图。

```text
模型输出 logits: 4×H×W
        ↓ sigmoid
像素概率:         4×H×W
        ↓ threshold
二值 Mask:        4×H×W
```

## RLE 是什么？

RLE 是 Run-Length Encoding，只是一种 Mask 压缩格式，不是机器学习算法。

例如一维 Mask：

```text
0 0 1 1 1 0 0 1 1 0
```

可以写成：

```text
3 3 8 2
```

含义是“从第 3 位起连续 3 个 1，从第 8 位起连续 2 个 1”。

本竞赛有两个特殊点：

1. 起始位置从 1 而不是 0 开始；
2. 图像按照列优先（Fortran order）展开。

错误使用行优先会让 Mask 转置或错位，所以环境检查会做 RLE 往返测试，样本脚本还会把 Mask 叠加到原图。

## Dataset 与 DataLoader

- `Dataset` 定义“如何读取一张图片和它的四张 Mask”。
- `DataLoader` 负责把多张样本组成 batch、打乱顺序和并行读取。
- `batch size=4` 表示一次将 4 张图送进 GPU。

## Resize 的取舍

原图是 `256×1600`。本项目起步使用 `256×800`：保留高度，只将宽度缩小一半。

这不是最佳尺寸，只是速度与细节的折中。不要缩成 `224×224`，否则长宽比和细小缺陷都会严重改变。显存允许时可以进一步比较 `256×1600` 或横向 patch。

## 类别不平衡有两层

1. **类别之间不平衡**：Class 3 很多，Class 2 很少。
2. **像素之间不平衡**：一张图中背景像素远多于缺陷像素。

所以后续会比较 BCE-Dice 和 Focal-Dice，而不是只看整体像素准确率。一个全部预测为背景的模型可能有很高 accuracy，但没有实际检测能力。
