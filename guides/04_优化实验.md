# 04｜候选模型与优化实验

## A1：验证老师模板中的 DeepLabV3+

保持 ResNet34、BCE-Dice、基础增强、输入尺寸和 epoch 不变，只将 U-Net 换成 DeepLabV3+：

```bash
python train.py \
  --data-dir /root/autodl-tmp/kaggle/severstal-steel-defect-detection \
  --output-dir /root/autodl-tmp/kaggle/outputs/A1_deeplab_bce \
  --architecture deeplabv3plus \
  --encoder resnet34 \
  --encoder-weights imagenet \
  --loss bce_dice \
  --augmentation basic \
  --height 256 \
  --width 800 \
  --epochs 15 \
  --batch-size 4 \
  --learning-rate 0.0003 \
  --num-workers 4
```

### DeepLabV3+ 知识点

DeepLabV3+ 使用 ASPP：通过多种空洞率同时观察不同范围。小感受野关注细小缺陷，大感受野关注大面积缺陷，然后融合成多尺度特征。

只有当 A1 在同一验证集优于 B0，才能较有依据地说 DeepLabV3+ 在本实验中有效。Kaggle 强方案中有人报告 DeepLabV3 表现不好，因此它不能被预先称为“优化模型”。

如果 O1 有效，再保持模型和 Loss 不变，只把：

```bash
--augmentation basic
```

改成：

```bash
--augmentation strong
```

并将输出目录改为 `O2_fpn_focal_strong`。这样可以单独判断数据增强是否有效。

## Focal Loss 知识点

Focal Loss 是 BCE 的改进。它降低已经容易分类的背景像素权重，把更多训练注意力放在错误和困难像素上。本实现用 `alpha=0.75` 提高正像素相对权重，`gamma=2` 抑制简单样本。

这两个值是超参数，不是永远正确的常数。如果 Focal-Dice 没有提升，也应保留结果并分析，而不是隐藏实验。

## 强增强包含什么？

- 水平翻转；
- 轻微亮度和对比度变化；
- 轻微 Gamma 变化；
- 少量高斯噪声。

增强仅用于训练集。验证集不能随机增强，否则每次验证答案的输入条件不同，分数无法稳定比较。

## 不要过早加入的内容

- 大规模模型集成；
- 伪标签；
- 复杂 patch 拼接；
- 大量未经验证的增强；
- 为追分而频繁观察测试榜。

申请项目更看重清晰的问题定义、实验控制和分析能力，而不是堆砌所有 Kaggle 技巧。
